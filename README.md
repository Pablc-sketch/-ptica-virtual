# Óptica virtual

Óptica online premium con marcos en 3D interactivos.

- Next.js + Tailwind + React Three Fiber (three, drei)
- Supabase propio (proyecto `optica-virtual`, región sa-east-1), independiente de Lentia

```bash
cp .env.example .env.local   # completar la clave publishable
npm run dev
```
